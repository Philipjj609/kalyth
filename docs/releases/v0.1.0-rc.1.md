# Kalyth 0.1.0, release candidate 1

Tagged on 23 October 2026 for the Nebius x NVIDIA Global AI Hackathon, ahead of the 25 October
release-candidate date. It is the build the demo video and the newcomer session use. What it
does is in the [README](../../README.md); this note says what was checked and what is known not to
work.

## What was checked

- **Tests.** 510 unit and integration tests, and 63 browser tests of the main flows by keyboard
  with automated accessibility checks (57 of the local workbench, 6 of the hosted demo), pass in
  CI on Linux and Windows. The secret scan and the demo image build pass too.
- **The demo, end to end.** The video's shot list ([walkthrough](../demo/walkthrough.md)) was
  rehearsed on a fresh import of the committed demo template, replaying the Nemotron run recorded
  against Nebius Token Factory, at the video's layout.
- **A real agent hand-off.** Claude Code, logged in, took a task through Kalyth's MCP interface in
  an isolated project and repository: it claimed the task, read the context package, committed a
  change with the task trailer and reported. Kalyth's git verification passed and reconciliation
  showed what the commit changed in the model. The walkthrough records exactly what Claude Code
  did, apart from an earlier run by a scripted stand-in.

## Known limitations

- The analyser is static and reads FastAPI routes and SQLModel tables; other frameworks appear as
  modules, imports and libraries. Nothing from an analysed repository runs, and "observed" never
  means the code works. See the README's Limitations.
- The Navigator has no typed way to propose a new field of an existing entity, so the model may
  propose one as an entity of its own (`User.org_id`); reconciliation then finds no element of
  that name. A typed fix needs a prompt change and a new recording, after this candidate.
- An agent's tests are its own claim. In the rehearsal Claude Code ran none, because its
  permissions did not allow them, and said so.
- The hosted demo is built and tested but not deployed. Its MCP endpoint stays off until it is
  tested there.
- The evaluation run against frozen ground truth has not been done.
- No screen-reader pass has been done; the browser tests check axe's WCAG 2.2 A and AA rules, which
  find only part of what affects people.

## Spend

Every Nemotron answer the demo shows is a recording, replayed at no cost. Recording used Nebius
inference under capped ledgers approved in the coordination queue; this candidate needed no new
spend.
