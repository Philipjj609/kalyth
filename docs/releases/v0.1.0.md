# Kalyth 0.1.0, the competition release

Tagged on 26 October 2026 for the Nebius x NVIDIA Global AI Hackathon. It is the version the hosted
demo runs, at [kalyth-demo.fly.dev](https://kalyth-demo.fly.dev/), through judging (15 December
2026). What Kalyth does is in the [README](../../README.md); this note says what changed since
[0.1.0-rc.1](v0.1.0-rc.1.md), what was checked, and what is known not to work.

Kalyth is developed by Philip Ciuca, an individual developer, with extensive AI assistance: Claude
Code for most of the implementation, and other AI tools, ChatGPT among them, for research,
architecture, testing and review.

## Since 0.1.0-rc.1

- **The hosted demo is live** on Fly.io, in a dedicated organisation, with one small machine and a
  1 GB volume ([deploy/README.md](../../deploy/README.md)). Each visitor gets a private copy of the
  analysed FastAPI template. A security review before staging added traffic shares per address, a
  reserve for judges, request and sandbox size limits, and sandboxes on the volume
  ([ADR 0019](../adr/0019-hosted-demo.md)).
- **Live runs on Nemotron 3 Super.** The demo's four presets replay Nemotron 3 Ultra answers,
  recorded once on Nebius, for free. A request a visitor writes runs live on Nemotron 3 Super,
  reasoning within a budget, with one attempt. The gateway learned live models with their own
  reasoning settings and output caps, and the UI offers a live run only when the day's allowance
  covers its worst case. Three configurations were measured before choosing this one (ADR 0019,
  "Live runs on Super").
- **A first visit is clearer, and phones work.** An empty Situation page says what Kalyth does and
  offers a recorded change request; presets open their change thread; the workspace adapts to a
  phone's width. Wording now names the models used and how alternatives are cited.
- **The demo video** shows a real, unattended Claude Code hand-off over MCP
  ([docs/demo/recording.md](../demo/recording.md)), with the agent prompt quoting the task's notes.
- **Documentation**: the README describes the live demo, local analysis, the hand-off, the evidence
  so far and the limits; the submission text is in [docs/hackathon](../hackathon/submission.md).

## What was checked

- **Tests.** 532 unit and integration tests, and 64 browser tests of the main flows by keyboard,
  with axe's WCAG 2.2 A and AA rules in both themes (57 of the local workbench, 7 of the hosted
  demo, one at phone width). They pass in CI on Linux and Windows, with the secret scan and the
  demo image build, on the tagged commit.
- **The hosted demo, on the deployed tag, without spending:** recorded playback, a visitor's
  private copy, judge access, the refusals (no MCP endpoint, oversized bodies, requests without
  the UI header or from another origin), the daily allowances and the resource audit. The results
  are recorded in the coordination queue.
- **Live inference** was measured before release, within an approved 0.50 USD staging share, of
  which 0.039 USD was used.

## Reproduce it

```bash
git clone https://github.com/Philipjj609/kalyth.git && cd kalyth
git checkout v0.1.0
pnpm install --frozen-lockfile
pnpm check && pnpm build
pnpm demo:serve            # the hosted demo, locally, with recorded runs only
docker build -t kalyth-demo:v0.1.0 .   # the image the demo runs
```

The demo is deployed by hand from a clean checkout of this tag (`fly deploy --local-only`), never
automatically on a push.

## Known limitations

- **Static analysis, two frameworks.** The analyser reads Python and TypeScript; it finds FastAPI
  routes and SQLModel tables, and shows other frameworks as modules, imports and libraries.
  Nothing from an analysed repository runs, and "observed" never means the code works.
- **New fields as entities.** The Navigator has no typed way to propose a new field of an existing
  entity, so a model may propose `User.org_id` as an entity of its own.
- **An agent's tests are its own claim.** Kalyth verifies the commit against git, not the tests.
- **The hosted demo is narrower than local Kalyth:** one project, no imports, no agent access over
  MCP, and a few live runs a day. Live alternatives on Super are briefer than the recorded Ultra
  ones. Nebius accepted the reasoning budget but does not document it, and the one test stayed
  under it, so its enforcement is unverified; the output cap bounds the cost either way.
- **The independent evaluation has not run.** Its truth is frozen; the run follows the submission.
- **No screen-reader pass** has been done; axe finds only part of what affects people. On a phone
  the canvas works but is best on a wider screen.
